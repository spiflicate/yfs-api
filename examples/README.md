# Examples

These examples import only from the package root and are compiled by
`bun run type-check:examples` after `bun run build`.

- `01-public-read.ts`: OAuth 1.0 public read
- `02-oauth-state-and-storage.ts`: OAuth state and token persistence
- `03-nested-read.ts`: parent-preserving nested response traversal
- `04-roster-confirmation.ts`: roster write confirmation or `undefined`
- `05-raw-xml.ts`: unparsed XML access

Examples are not run by CI and do not contain credentials.
