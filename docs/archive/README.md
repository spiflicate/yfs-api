- [TRANSACTIONS.md](TRANSACTIONS.md) — Yahoo transactions protocol history (read, create, modify, cancel). Overlaps the current `resources/TRANSACTIONS.md` but includes detailed XML samples retained for protocol debugging.
- [yahoo-developer-docs-capture-2026-05-14.md](yahoo-developer-docs-capture-2026-05-14.md) — Firecrawl capture of the Yahoo Fantasy Sports API reference page as it appeared on 2026-05-14. Updated guide content is in [`../yahoo-fantasy-api-guide/`](../yahoo-fantasy-api-guide/). This capture is preserved for historical comparison.
